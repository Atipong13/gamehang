# 💣 Gamehang — วงกลมระเบิด

เกมเล่นกับเพื่อนแบบเรียลไทม์ ส่งระเบิดต่อกันในวงกลม ใครถือตอนแตกตกรอบ คนสุดท้ายชนะ
คะแนนผู้ชนะเก็บในไฟล์ `data/scores.json` (ไม่มี DB)

## รันในเครื่อง
npm install
npm start
เปิด http://localhost:3000 (เพื่อนในวง Wi-Fi เดียวกันเข้าผ่าน IP เครื่องคุณ เช่น http://192.168.x.x:3000)
